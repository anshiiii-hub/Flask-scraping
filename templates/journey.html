My Learning Journey

A six-week deep dive into Data Analytics & Engineering at CodroidHub, chronicling my skill progression from foundational concepts to full-stack deployment.

W1

Week 1: Python & Foundations

The journey began by architecting a solid foundation in Python, mastering programming logic, data structures, and the high-performance libraries—NumPy and Pandas—that form the bedrock of any serious data analysis.

Core Competencies Unlocked:

Core Python NumPy Pandas

Key Project:

Developed a script to analyze a sales dataset, performing data cleaning, aggregation, and calculating key metrics with Pandas.

W2

Week 2: Web Scraping & Data Acquisition

This week focused on transforming the web into a limitless data source. I engineered robust scrapers using BeautifulSoup and Selenium, mastering techniques to automatically gather, parse, and structure information from diverse websites.

Core Competencies Unlocked:

BeautifulSoup Selenium Data Cleaning

Key Project:

Built a scraper for `books.toscrape.com`, successfully extracting and structuring data for over 1,000 book entries into a clean CSV file.

W3

Week 3: Data Analysis & Visualization

With a strong pipeline for data acquisition, this week was dedicated to turning raw data into compelling stories. I dove into time-series analysis and mastered industry-standard tools like Tableau and Power BI to build interactive, insightful dashboards.

Core Competencies Unlocked:

Time-Series Analysis Power BI Tableau

Key Project:

Created an interactive Power BI dashboard to visualize findings from the "Books to Scrape" dataset, showcasing price distributions and availability trends.

W4

Week 4: SQL Fundamentals

This week was a deep dive into mastering SQL, the universal language of data. I learned to architect and query complex relational databases, performing powerful joins and aggregations to efficiently extract precise information for large-scale analysis.

Core Competencies Unlocked:

Advanced SQL Database Design Query Optimization

Key Project:

Designed a relational schema and populated a database with scraped data, then executed complex queries to aggregate sales data by category.

W5

Week 5: SQL & Python Integration

Bridging the gap between application logic and data storage. This week focused on architecting end-to-end solutions where Python scripts and SQL databases communicate seamlessly, enabling dynamic, data-driven applications.

Core Competencies Unlocked:

Database APIs Pandas Integration Automation

Key Project:

Developed a Python application that connected to a SQL database, executed queries dynamically, and exposed the results through a simple API endpoint.

W6

Week 6: Deployment with Flask

The final week brought all the preceding skills to a culmination. I mastered the Flask framework to build and deploy full-stack web applications, learning to turn complex data analyses into interactive, production-ready projects.

Core Competencies Unlocked:

Flask Jinja2 Full-Stack Development

Key Project:

Built and deployed a complete Flask web application that visualized the IPL data analysis, complete with dynamic charts and a downloadable CSV report.

Transformation: From Theory to Application

Over six weeks, this intensive training transformed foundational knowledge into a versatile, professional skillset. I am now equipped with the end-to-end capabilities to tackle complex data challenges—from initial data acquisition and engineering to sophisticated analysis, visualization, and full-stack deployment.
